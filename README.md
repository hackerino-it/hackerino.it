# Hackerino.it

Sito editoriale statico dedicato alla sicurezza digitale quotidiana, progettato per essere pubblicato su GitHub Pages con il dominio `hackerino.it`.

## Stato del progetto

- Prima identità visiva completata.
- Homepage responsive con ricerca e filtri per le guide.
- Prima guida pubblicata: “Ho cliccato su un link sospetto”.
- Pagine “Chi siamo”, privacy preliminare e pagina 404 presenti.
- Metadati social, sitemap, robots.txt e dominio personalizzato predisposti.
- Repository GitHub creato e pubblicazione automatica attiva sul branch `main`.
- Google AdSense non è ancora installato.

## Struttura

- `index.html`: homepage.
- `guide/`: articoli e guide.
- `assets/`: stile, JavaScript e immagine social.
- `chi-siamo.html`: manifesto e metodo editoriale.
- `privacy.html`: informativa preliminare da completare prima del lancio.
- `.github/workflows/pages.yml`: pubblicazione automatica.
- `CNAME`: associazione prevista con `hackerino.it`.

## Prima della pubblicazione

1. Completare titolare, recapiti e responsabilità editoriale.
2. Configurare `hackerino.it` come dominio personalizzato.
3. Correggere i record DNS senza modificare gli eventuali record email MX.
4. Verificare HTTPS e collegamenti dopo la propagazione DNS.

## Prima di AdSense

- Pubblicare una raccolta consistente di contenuti originali.
- Completare privacy policy, cookie policy, titolare e contatti.
- Installare una CMP certificata per il consenso degli utenti europei.
- Verificare le regole AdSense e posizionare gli annunci senza interferire con contenuti o navigazione.
